T68k Browser Helix Keybinding Cheat Sheet

Key Mode Action Description
j / k Normal Scroll down / up (supports counts like 5j)
h / l Normal Scroll left / right
d / u Normal Half-page scroll down / up
f Normal Open link hint mode in current tab
F Normal Open link hint mode in background tab
v Normal Enter Visual / Selection mode for text carets
/ / ? Normal In-page search forward / backward
n / N Normal Jump to next / previous search match
: Normal Helix command prompt (:tabnew, :b, :theme, :q)
<Space> Normal Open Space Menu (Tab picker, Bookmarks, History, Yank)
<Space> b Normal Fuzzy tab/buffer switcher
g g / g e Normal Jump to top / bottom of webpage
g h / g l Normal Go back / forward in browser history
] h / [ h Normal Jump to next / previous heading
] l / [ l Normal Jump to next / previous link
] i / [ i Normal Jump to next / previous input field
] b / [ b Normal Jump to next / previous button
y y Normal Yank page URL to clipboard
y f Normal Yank target link URL via hints
w / b / e Select Extend visual selection by word
x Select Extend visual selection to whole line / block
y Select Yank selected text and return to Normal mode
Esc / jk Insert Exit text input back to Normal mode
